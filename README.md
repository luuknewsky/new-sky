# new-sky

Skill-bibliotheek voor New Sky. Elke skill staat in een eigen map onder .claude/skills/.

## Een skill installeren

Gebruik de URL van de map van de skill zelf, niet die van de repo.

Goed:
https://github.com/luuknewsky/new-sky/tree/main/.claude/skills/naam-van-de-skill

Fout:
https://github.com/luuknewsky/new-sky

## Structuur

Zie .claude/skills/README.md voor de mapindeling en het format van SKILL.md.
